# Purrcept 移动体验（Purrcept Cel v0.4 · 社交情感陪伴升级）

`Purrcept Go` 采用 **Purrcept Cel v0.4.0（清透学园 × 暖调手账）** 设计语言，通过 `design/purrcept-cel.tokens.json` 与 `tooling/export_cel.py` 导出移动端专属 Token，告别原生 Android Material 默认扁平列表，塑造兼具二次元清透质感与社交软件温度的随身陪伴空间。

## 视觉语法与微动效

- **清透学园氛围底板**：聊天与设备页共享天青×暖桃径向柔光画布与右上角半调网点（`CelAtmosphereScaffold`），深浅色自动适配。
- **赛璐璐硬边描边与零模糊投影**：主面板、社交顶栏、底栏与交互胶囊采用 `1.5dp` / `2.0dp` 清晰描边及零模糊硬边偏移阴影（`CelSurface`、`CelPressButton`），按压时带有 `80ms` 吃掉阴影的下沉回弹手感。
- **不对称对话气泡与时间轴分组**：Bot 与用户气泡分别收窄左上/右上尖角，配以双端独立头像与时间分组胶囊，还原熟悉而耐看的即时社交聊天节奏。
- **探出头前景状态横幅（Peeking Mascot Banner）**：输入区上方的实时状态条采用前景不透明色带遮挡吉祥物下颌，呈现“趴在横幅后探出头陪伴”的空间层次；安静待命时保持静态底色，专注推理、执行动作或倾听输入时切换柔和的动态色潮与声波微效，并严格遵循系统“减少动态效果”设置。

## 社交陪伴核心能力

- **双端自定义头像与昵称工坊（`AvatarStudioSheet`）**：支持分别为 Bot 与用户设置本地相册裁切照片、6 款内置学园风矢量预设头像或默认动态猫咪/首字母徽章，并可自定义“我的昵称”，由原生 Room 持久保存。
- **贴纸与自定义表情抽屉（`StickerDrawerPanel`）**：内置 12 款陪伴微表情矢量贴纸（探头、摸摸头、星星眼、抱抱、应援、思考、打盹、气鼓鼓、收到、喝茶、摇尾巴、呆毛震惊），呈无框模切大贴纸展示；同时支持从相册导入自定义表情包或长按聊天图片一键“收藏为表情”。
- **按住说话与语音波形气泡（`VoiceRecorder` + `VoiceMessageBubble`）**：支持按住说话（上滑取消）及无障碍点击录音模式，原生采集 `16 kHz` 单声道 `PCM16 WAV` 并实时展示音量律动浮层；语音气泡内置 22 段振幅波形条与播放进度交互，麦克风权限仅在首次触发录音时按需申请。
- **图片分享与长按引用回复**：支持发送相册图片（自动缩放压缩并缓存缩略图），长按任意消息可唤起引用回复、复制文本、收藏表情与真实投递回执抽屉。

## 状态可证与跨端协议兼容

- **真实投递状态，绝不伪造“已读”**：严格区分“已保存在本机”“Engine 已接管 · 等待同步”“已同步到这台手机”以及 `engine.state` 实时阶段，断线立即停止工作动画，主体名称始终从配对/配置动态读取而不硬编码特定人设名。
- **`rich_chat` 多模态协议与向下兼容**：当桌面端 `Purrcept-Engine` 声明 `rich_chat` 特性时，语音（`AudioBlock`）、图片/自定义贴纸（`ImageBlock`）与引用关系通过 `/phone/v1/media` 及扩展 `chat.submit` 双向同步，Bot 亦可主动发送贴纸或语音回复；连接旧版 Engine 时自动回退为标准三字段纯文本载荷，本机富媒体展示不受影响。
